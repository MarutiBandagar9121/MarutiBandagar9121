### 🚀 Featured Projects

**[ContextHub](https://github.com/MarutiBandagar9121/ContextHub)** — Multi-tenant RAG platform
Microservices architecture with domain-driven service boundaries; stateless cross-service auth via asymmetric RS256 JWTs, async inter-service calls over HTTPX.
`Python` `FastAPI` `PostgreSQL` `Docker` `Celery` `RabbitMQ`

**[SpaceGraph](https://github.com/MarutiBandagar9121/spacegraph)** — Office leasing inventory on a graph database
Matches client requirements against commercial office inventory, and finds physically adjacent units/floors that can be combined into one deal — a query graph databases handle naturally and relational schemas don't. [Live demo](https://spacegraph-six.vercel.app)
`TypeScript` `Graph DB (CognoDB/Neo4j-style)` `FastAPI`

**[Swaadishtha](https://github.com/MarutiBandagar9121/swaadishtha-django)** — Full-stack marketplace e-commerce platform
Production-grade data layer: UUID keys, purpose-built indexes, attribute-based product variants, and GST-compliant (SGST/CGST/IGST) invoicing.
`Django` `PostgreSQL`

**[indian-id-validator](https://www.npmjs.com/package/indian-id-validator)** — Published npm package
Validates Aadhaar, PAN, GST and Indian mobile numbers with Verhoeff checksum support; ships as ESM + CJS with full TypeScript types.
`TypeScript` · [npm](https://www.npmjs.com/package/indian-id-validator) · [source](https://github.com/MarutiBandagar9121/indian-id-validator)

**[Quiz Management Platform](https://github.com/MarutiBandagar9121/laravel-quiz-management)** — Admin-built quizzes with attempt history & scoring
Guest and registered-user flows, documented architecture and data-model decisions.
`Laravel 13` `Livewire` `MySQL` `Tailwind`
